HOW I BUILD / 04

我做工程的六条原则

这些是贯穿所有项目的习惯，也是我希望在面试中被检验的地方。

P-01

可复现 / 离线可演示

确定性脚本引擎、未配置 Key 自动 mock、随机过程显式 seed。面试现场断网，系统也能端到端跑起来。

P-02

安全是默认项

密钥只在服务端、.env 不入库、最小权限；高风险动作走人工授权；演示一律用合成/模拟数据，工具仅限授权环境。

P-03

测试与质量门

pytest / Vitest / Playwright、tsc 类型门、Python 静态校验、CI；数据先校验再入引擎，不把脏数据喂给系统。

P-04

真实闭环，不做玩具

真实数据库、真实打卡、真实使用：为自己的训练、刷题、内容生产解决问题，dogfooding 驱动迭代。

P-05

工程化与文档

src/tests/docs 分层、一键启动脚本、版本备份与回滚、README 与 Checkpoint 记录，让项目三个月后还能跑、能交接。

P-06

诚实的 AI 协作

透明使用 AI 辅助编码，但架构决策、验证与结果由我负责；提交历史真实、不回填，哪些是 AI 写的、哪些是我定的，分得清。

SYSTEMWIRE 内网安全智能体平台

CONVERSATIONAL AI SECURITY AGENT · HITL · MITRE ATT&CK
背景与问题

对话式安全 Agent 很容易停留在"能聊天、不能落地"：要么直接调用工具带来误操作风险，要么演示依赖外部大模型与网络、现场不可控。我希望做一个能在面试现场断网 100% 复现、且把"人工授权"做成一等公民的安全运营智能体。

我的职责

独立完成产品定义、三栏控制台 UI、确定性演示引擎、Agent 运行时编排、HITL 授权流与 50 个测试用例。技术栈 Next.js 15 / React 19 / TypeScript / CopilotKit 1.73。

关键决策与技术取舍
  • 确定性演示引擎拦截 OpenAI 兼容接口：用状态机 + SSE 流式逐条产出，脚本驱动资产测绘、蜜点部署、威胁归因；真实 DeepSeek 可用时走真模型，失败自动回退脚本，演示永不中断。
  • 高风险动作必须 HITL：部署/卸载蜜点弹出授权卡，展示终端命令、利弊、影响评估；端口冲突时给出"换端口 / 停旧实例 / 换 IP / 中止"四方案，Agent 无权自行执行。
  • 信息分层不重复：AI 只输出 1–2 句结论，明细交给 Artifact 卡片（拓扑、告警、图谱）与右栏控制台（态势、告警队列、置信度），三处各司其职。
难点与结果

难点在于流式状态编排与"自动化程度 vs 可控性"的平衡。最终交付 3 个运营场景（内网体检 / 蜜点部署 / 威胁归因）、12 资产 9 告警的完整剧本、L1–L4 杀伤链 + 四因子置信度（主样本 87%）归因，以及悬浮助手、侧边栏、嵌入式终端、MCP 应用等 10 条路由；50 个 Vitest 用例 + tsc 类型门，离线一键可跑。

半程马拉松训练管理 Web App

HALF-MARATHON TRAINING OS · NEXT.JS + SUPABASE + PWA
背景与问题

为冲击男子半马国家三级标准（1:21:30），我需要一个真正每天用的训练系统：课表、打卡、统计、AI 建议都要可靠，而不是只在演示里出现一次的 demo。

我的职责

独立设计 12 张表的数据模型、服务端 API、PWA 前端、离线同步与测试；技术栈 Next.js（App Router）/ TypeScript / Supabase / Tailwind / Vitest + Playwright。

关键决策与技术取舍
  • 密钥零暴露：浏览器不直连 Supabase，Service Role Key 与 AI Key 只在服务端；HttpOnly Cookie + 访问码 + 限流，避免匿名公网部署被刷。
  • AI 建议可回滚：建议先暂存，用户确认才应用；应用前自动写入 plan_versions 备份，失败由 Postgres RPC 事务整体回滚，不会把课表改坏。
  • 离线优先：Service Worker + IndexedDB 打卡队列，断网先记、联网补传；PWA 可安装到桌面/手机；提供 bat/cmd/ps1/sh 一键本地脚本。
难点与结果

难点是弱网/离线的数据一致性与 AI 改课表的安全性。最终覆盖 7 个训练阶段 + 12 周逐日计划、5 个 Checkpoint 评审，关键链路有 Vitest 单测与 Playwright 端到端测试，是我自己一直在用的产品。

GitHub 源码需自备 Supabase（提供 .env.example 与初始化脚本）
