## 本地预览

直接用浏览器打开 `index.html` 即可；或在本目录启动任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 目录

- `index.html`：单文件站点（内联 CSS / JS，无构建步骤）
- `assets/img/`：SYSTEMWIRE 项目的本地真实运行截图（WebP）

截图均为本地真实运行所得；SYSTEMWIRE 为纯前端模拟的安全智能体，安全工具仅限授权环境使用。
